Key data flows

FlowFrom → ToDataReport ref
Lead to quoteLead sources / Staff → CRMEnquiry, site survey, versioned quotation, approval, e-accept§3, C2, C5, C9
Quote to cashCRM → Sales → Invoicing → CustomerOrder, delivery, GST-capable invoice, payment; Invoicing works even if Finance is off§4.3, Q7
Financial postingInvoicing / Purchase / Payroll → Event bus → FinancePosting events turned into journals by an adapter; no event means no couplingAR3, §9.3
Procure to paySales / Inventory → Purchase → SupplierStock shortfall, RFQ, PO, GRN, 3-way-match bill, payment§4.3
Hire to payEmployee → HR → Payroll → BankAttendance, leave, salary structure, payroll run, payslip, payment status§4.2, R1
Sale to serviceSales → Assets → Helpdesk → Field ServiceSerial-tracked asset, warranty/AMC, ticket, dispatch, job completion§4.3, R5
ConfigurationTenant Admin → CoreModule toggles, roles, pipelines, custom fields, workflows, Industry/Localisation packs§9.4
AuditAll modules → Audit logField-level change log with retention§6
